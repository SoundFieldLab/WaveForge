## 1. 定位与设计目标

v3 是给 **WaveForge** 设计的第三代音频效果引擎，与 v1（Web Audio 节点图）、v2（Web Audio 节点图 + 服务）
**完全独立**：纯 TypeScript 的 DSP 内核，不依赖 Web Audio 节点，可在任何 JS 运行时（浏览器、Worklet、
Node、Electron 主/渲染进程）以同一份代码跑出**逐样本一致**的结果。

| 目标 | 具体含义 | 落地方式 |
|---|---|---|
| 双路径一致 | 实时播放与离线导出共用同一内核 | `EngineV3.process` 是唯一处理入口，worklet/script/离线三处都调它 |
| 确定性 | 同输入 + 同参数 ⇒ 同输出（位级） | 禁止 `Math.random`/`Date`/`console`；系数全部显式初始化 |
| 可测试 | 无浏览器依赖即可完整单测 | AudioNode 全部鸭子类型（stub）；DSP 模块纯函数式接口 |
| 零分配稳态 | 实时线程无 GC 抖动 | `process()` 内零分配，工作缓冲惰性扩容 |
| 参数安全 | 恶意/越界参数不产生 NaN/爆音 | 所有频率/增益/Q clamp；白名单解码；NaN/Infinity 拒绝 |
| 许可合规 | 不碰 GPL；LGPL 只链接不改 | soundtouchjs 以"不修改源码 + 动态 import 调用"使用（用户策略） |

**关键架构决策（ADR 摘要）**：

1. **纯 TS 内核而非 Web Audio 图**：节点图在 128 帧量子下跨节点开销大、离线/实时难对齐；纯内核
   双路径天然一致，也方便把引擎塞进 AudioWorklet 单文件。
2. **v2/v3 完全独立，不写兼容层**：v3 有自己的参数模型（`V3EngineParams`）与宿主（`EngineV3Host`），
   切换语义与 v2 相同（先断后连），但参数不迁移。
3. **参数快照语义**：`setParams` 每次收完整快照并整体替换，模块 setParams 即算系数、即时生效；
   不做增量 diff，避免状态分叉。
4. **设备档案移除（2026-08）**：不引入真实设备档案（AutoEq 测量数据/拟合全部不用）；
   "机型频响补偿"改为 **LoudnessComp auto 按音量通用曲线**（音量越低 → 低频 0-12dB / 高频 0-6dB 提升）。
5. **LGPL 链接合规**：soundtouchjs(LGPL-2.1) 原包副本随 `vendor/` 分发（含 LICENSE），
   适配层 `StretchLgplAdapter` 只调公开 API，不修改源码；动态 import 按需加载。

### DSP 模块一览（16 模块 + 适配层）

| 模块 | 文件 | 算法出处 | 关键边界处理 |

| M/S | `MidSide.ts` | 公有 2×2 矩阵 | 对称 vb 公式；width=0 退单声道 |
| 齿音抑制 | `Deesser.ts` | Stanford EE264 论文思路 | 侧链带通 + LR-4 交叉；分带/宽带 |
| 压缩器 | `Compressor.ts` | DaisySP（MIT）接口思路 | 软拐点；1/4 斜率 ±0.1 |
| 限幅器 | `Limiter.ts` | DaisySP + 自研 | 前瞻 + 4× 过采样真峰值；零过冲 |
| 虚拟低音 | `BassEnhancer.ts` | IEEE 虚拟低音论文 | 4 种谐波非线性；even→120Hz；**低音下潜 lowBoostDb 真实低频提升（lowshelf 语义）** |
| 卷积混响 | `Convolver.ts` | DAFX 分区卷积论文 | 滑动窗口 + 动态扩容；IR 去周期化；块长 128–4096 对拍 |
| 算法混响 | `ReverbSimple.ts` | Freeverb（stk MIT） | 5 类型；能量单调衰减 |
| 响度计 | `LufsMeter.ts` | ITU-R BS.1770/EBU R128 | K 加权 + 门限；LRA/真峰值 |
| 等响度补偿 | `LoudnessComp.ts` | ISO 226 简化（v2 兼容公式） | **auto 按音量通用曲线**；f0 clamp |

## 4. 处理链（EngineV3.process，14 级）

顺序**固定**（API_SPEC 辅助模块 A 亦登记）：

```
输入
 ├─ 1) 响度归一化   （实时 BS.1770 测量驱动或外部增益；自动分支 3s 平滑防抽吸、手动音量分支 80ms 跟手；无测量期 0dB）
 ├─ 2) 3D 环绕      （轻量立体声旋转：angle 静态 + speed 慢旋；distance→电平）
 ├─ 3) M/S          （width + voiceBalance；voiceBalance 仅 pitch.enabled 时生效）
 ├─ 4) Pre-EQ       （用户 EQ：simple 5 段 / pro 10-20 段 + 级联 Q 补偿；eq.enabled 门控）
 ├─ 5) Deesser      （分带/宽带齿音抑制）
 ├─ 6) Compressor   （软拐点动态压缩）
 ├─ 7) NightMode    （压缩增强 + 6kHz 高频衰减，v2 语义）
 ├─ 8) 混响         （三路路由：卷积 | 算法 | off；off=完全直通）
 ├─ 9) BassEnhancer （虚拟低频谐波 + 低音下潜 lowBoostDb：低通提取低频带按增益混回，真实低频能量）
 ├─ 10) LoudnessComp（等响度补偿：auto/preset/custom；auto=按音量通用曲线）
 ├─ 11) IEQ(Post)   （智能均衡：flat/warm/bright/vocal 目标曲线，3s 慢速平滑防抽吸）
 ├─ 12) [LUFS 取样点]（Limiter 之前，测压限前节目响度）
 ├─ 13) Limiter     （前瞻 + 真峰值，默认 -1dBFS）
 └─ 14) 输出
```

**链设计理由**：
- **响度归一化在最前**：统一输入电平，后续压缩/限制的阈值语义稳定；
- **Pre-EQ 在动态处理之前**：EQ 造成的峰值变化由压缩器/限幅器兜底；
- **LoudnessComp 在 IEQ 之前、限幅之前**：补偿产生的提升先被 IEQ 整形、被限幅器兜底，避免削波；
- **LUFS 取样点在 Limiter 之前**：测的是节目响度而非限幅后的峰值限制结果（API_SPEC 要求）；
- **IEQ 的分析取样在 LoudnessComp 之后**（即 IEQ 输入处），闭环反馈无延迟感。

**旁路语义**：每个效果模块 `enabled=false` 时逐样本直通（审计断言 diff=0）；
全关时输出与输入逐样本一致（≤1e-12 浮点容差）。

**分析路径**：`getAnalysis()` 在链内取样（2048 点 FFT，位于 LoudnessComp 之后），
输出频谱 + 特征（rms/质心/滚降/平坦度/波峰因子），供 UI 可视化与 IEQ 输入。

**latency**：由卷积混响分区长 + 限幅器 lookahead 决定，`getLatencySamples()` 精确报告；
混响 mode='off' 或算法混响时卷积链路直通、不贡献延迟。

## 5. 参数模型（types.ts）

- **`V3EngineParams`**：全量参数快照，包含 eq / deesser / compressor / nightMode / bassEnhancer /
  reverb / surround3d / loudnessCompensation / loudnessNormalization / limiter / ieq / pitch /
  stereoWidth 等子设置（v2 命名兼容字段：proBands、simpleBands、voiceBalance、outputGain……）。
- **`bassEnhancer.lowBoostDb`（-6..+12dB，2026-08-18 新增）**：低音下潜——低通提取的低频带按
  `10^(lowBoostDb/20)−1` 混回（等价 cutoffHz 处 low-shelf），**真实低频能量提升**；谐波路径只提供
  心理声学感知。分享串编解码同步支持；增强/舞曲/深夜低音/温暖/流行场景已配不同档位。
- **`createDefaultParams(fs)`**：唯一默认值入口；所有数值可序列化（JSON 安全）。
- **快照语义**：`setParams` 整包替换 + 各模块系数重算；分享串/场景预设均以快照为交换单位。
- **`deviceProfile` 已移除**（2026-08）：机型补偿由 `loudnessCompensation.mode='auto'` 承担。

**LoudnessComp auto —— 按音量实施的通用补偿曲线**（替代设备档案）：

```
spl   = 50 + 30 × (volumePercent / 100)          // 音量 0-100 → 感知电平 50-80 dB SPL
lowG  = clamp((80 − spl) × 0.35, 0, 12)  dB      // 低频提升上限 12dB @ 120Hz LowShelf(Q=0.707)
highG = clamp((80 − spl) × 0.15, 0, 6)   dB      // 高频提升上限 6dB  @ 12kHz HighShelf(Q=0.707)
```

音量越低 → 低/高频提升越多；音量 100% 时补偿为 0（曲线平直）。测试覆盖
volumePercent=20 → 120Hz 提升 >3dB、1kHz ≈0dB（等响度感知的 v2 兼容公式）。

## 6. 双路径执行模型

```
                 ┌─────────────────────────────────────────────┐
 用户操作/参数 → │ EngineV3Host（浏览器侧接线）                  │
                 │  worklet 模式：AudioWorklet 内 EngineV3      │
                 │  script 模式：ScriptProcessor 内 EngineV3    │
                 └──────────────┬──────────────────────────────┘
                                │ 同一内核、同一参数
                 ┌──────────────┴──────────────────────────────┐
 离线导出 →       │ EngineV3.process 分块处理（解码 PCM → 链 → WAV）│
                 └─────────────────────────────────────────────┘
 一致性保证：worklet 与离线导出对同一输入+同一参数逐样本误差 <1e-6（测试断言）
```

**worklet 模式**：`AudioEffectsProcessor.ts` 经 esbuild 打包为单文件 `public/v3-worklet.js`，
处理器名 `waveforge-v3-effects`；参数经 `port.postMessage({type:'params'})` 下发，`stats` 周期回传。

**script 兜底**：`createScriptProcessor(4096)`，`onaudioprocess` 内直接调 `EngineV3.process`
（同一内核，无需打包即可先联调）；块长默认 4096（块长相关缺陷已修复，安全）。

**离线路径**：解码后的 PCM 按块喂给同一个 EngineV3 实例，写出 WAV；可与实时链逐样本对拍。

## 7. 引擎总成细节（EngineV3）

- **零分配**：`process()` 内不 new 任何对象；工作缓冲按需惰性扩容，稳态无分配。
- **确定性**：无随机/Date/console；同输入同参数 ⇒ 位级相同输出。
- **单/双声道**：`new EngineV3(fs, channels)`；单声道忽略第二输入。
- **热切换安全**：`setParams` 中途不会撕裂处理（块间生效）；参数突变由模块内部平滑/reset 兜底
  （Stretch 突变 reset、Limiter lookahead 重建保留增益、响度归一化外部增益一阶平滑——自动测量
  分支 3s 慢速防抽吸，手动音量分支 80ms 快平滑跟手）。
- **内置实现**：IEQ（目标曲线拟合）、NightMode、3D 环绕、响度归一化控制都在本文件内，
  不再拆 dsp 模块（避免过度抽象）。

## 8. 集成层（EngineV3Host）

公开 API：

```ts
new EngineV3Host(opts?: { mode?: 'worklet'|'script'|'auto'; workletUrl?: string;
                          processorName?: string; blockSize?: number; engine?: EngineV3 })
host.attach(handle: { audioContext; masterGain; analyser }, params?)  // 幂等
host.setParams(p: V3EngineParams)
host.dispose()        // 恢复 masterGain→analyser 直连
host.engine           // 引擎实例（惰性创建/注入）
```

**切换语义**（与 v2 dispose 相同约束，防新旧双链并联打架）：
1. attach：masterGain 全断 → 接入 v3 处理节点 → 连 analyser；
2. dispose：断开处理节点 → 恢复 masterGain→analyser 直连；
3. 幂等：重复 attach 同一 handle 直接 return；
4. 竞态：attach 异步注册期间被 dispose → 完成后放弃接线（防旧节点插进新图）。

AudioNode 均为鸭子类型（最小接口），Node 测试环境可用 stub 验证接线语义（`integration.test.ts` 9 项）。

## 9. 分享串与场景预设

**ShareCodec**（`engine/ShareCodec.ts`，自研）：
- 格式：`base64url("<version>:<checksum>:<json>")`，version 恒为 1（`SHARE_CODEC_VERSION`）；
- 校验：FNV-1a 32 位哈希（公有领域算法）覆盖 `version:json`，8 位小写十六进制；
- 安全：白名单解码（非法枚举回落默认、越界数值 clamp、长字符串截断、NaN/Infinity 拒绝）；
- 卷积 IR 数组序列化时降级为 `irName` 引用（避免超大串）。

**ScenePresets**（`engine/ScenePresets.ts`，自研）：
- 11 个组合场景（id 固定、顺序稳定），每个是全参数快照（含混响/补偿/EQ 等全部字段）；
- 场景切换 = setParams(快照)，A→B→A 热切换无爆音（审计断言）；
- 夜间/低频等补偿场景经四轮调平收敛到 -22.4dB 契约界内。

## 13. 已知边界与备查项

1. **卷积混响流式"末块尾截断"**：最后未满块的湿输出需后续输入冲刷（流式固有语义，文档已注）；
2. **3D 环绕级**未收录于 API_SPEC 模块 A（实现为链内轻量立体声旋转，差异已注释）；
3. **Limiter lookahead 变化**重建缓冲时 gain 复位台阶（热切换边界跳变 0.33 @0.5 幅度，有界）；
4. **部分场景 ~1e-3（-60dBFS）级微小 DC 残余**（偶次谐波整流+压缩包络调制，无累积、低于可闻阈值）；
5. **script 兜底块长默认 4096**：块长相关缺陷已修复（Convolver 滑动窗口+动态扩容），安全；
6. **声源分离**为任务队列 + 适配层，模型权重按 spleeter/demucs 各自仓库声明（ONNX 占位）。

# 空间音频：虚拟扬声器环绕去相关

## Problem Statement

虚拟扬声器上混的环绕声道主要来自左右差分（side）。当音乐是单声道、人声居中或左右高度相关时，side 接近 0，SL/SR/BL/BR 几乎没有信号，7.1.4 的 11 只虚拟扬声器实际只剩前方几只，听感又退回“耳机里的立体声”。需要一种不伪装成离散音轨、但能在相关/单声道内容上产生稳定后方与包围感的去相关机制。

## Solution

在 headLocked 的虚拟扬声器上混后增加可调的「环绕去相关」：用经过短延迟的 mid 信号（8–20ms，不同扬声器不同延迟）以低增益混入环绕声道，制造早期反射式的非相干后方能量；默认关闭，5.1 与 7.1.4 快捷预设分别带一个温和值，用户可在空间音频页调节。它与矩阵上混共用同一组虚拟扬声器，不改变真实多声道输入和 custom 布局。

## User Stories

1. 作为耳机用户，我想在单声道/居中人声的音乐里也能听到后方虚拟扬声器，而不是只有前方。
2. 作为用户，我想能调「环绕去相关」强度，从完全关闭到明显包围，找到适合自己的量。
3. 作为用户，我想默认保持干净的矩阵声，只有我开启或使用沉浸预设时才加入延迟反射。
4. 作为用户，我想 5.1 和 7.1.4 快捷预设自带一个温和的去相关值，不用每次手动设置。
5. 作为用户，我想真实多声道输入不被去相关处理，避免破坏原始环绕声。
6. 作为用户，我想 custom 两只扬声器布局不被强行加入后方延迟。
7. 作为用户，我想去相关不会改变左右声道的音量平衡或引起明显削波。
8. 作为开发者，我想去相关逻辑独立于 StereoUpmixer，保持纯矩阵上下混契约不变，便于测试。
9. 作为追求音质的用户，我想能选择早期反射阶数（0–3），这样可以在完整反射和计算预算之间取舍。

## Implementation Decisions

- 新增一个独立的去相关处理器概念，作用于 headLocked 上混后的环绕声道（5.1 的 SL/SR；7.1/7.1.4 的 SL/SR/BL/BR），不修改 StereoUpmixer 的输出或矩阵重建契约。
- 用 mid=(L+R)/2 的短延迟副本（左右不同延迟，约 8–20ms）低增益叠加到环绕声道；不同声道不同延迟降低相关性，不引入可辨的单一回声。
- SpatialSettings 增加 decorrelation 0..1（默认 0），随参数快照持久化；仅 headLocked + 立体声上混路径生效；真实多声道/custom 不处理。
- 沉浸空间 7.1.4 预设写入约 0.35；5.1 快捷预设写入约 0.2；UI 增加「环绕去相关」滑杆。
- 增加 `earlyReflectionOrders` 0..3（缺省由 budgetMode 推导）；沉浸预设用 3 阶，UI「反射阶数」滑杆可调。
- 不改变任何默认关闭时的样本输出；不改变 StereoUpmixer 既有测试的逐样本重建。

## Testing Decisions

- 测试单声道输入：decorrelation=0 时 SL/SR 仍为 0；>0 时 SL/SR 有能量且左右不完全相同。
- 测试默认 5.1/7.1 StereoUpmixer 输出逐位不变（现有回归）。
- 测试真实多声道输入和 custom 布局不进入去相关。
- 测试 UI 滑杆写入 decorrelation 且范围 0..1；沉浸预设同时写入 earlyReflectionOrders=3。
- 参考 stereoUpmixer.test.ts、spatial-virtual-speakers.test.ts。

## Out of Scope

- 用去相关伪装成真实后置音轨；它仍是派生反射。
- 改变 HRTF 或房间卷积核心。
- 对 AmbiX / 真实多声道做去相关。
- 离线 BRIR 预计算。

## Further Notes

去相关是“让相关内容也有后方反射线索”的工程手段，不是音源分离。过量会产生空间化过度/相位感，UI 默认值与快捷预设取温和值。

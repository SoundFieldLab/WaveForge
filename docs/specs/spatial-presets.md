# 空间音频：我的空间方案（本机保存/快速对比）

## Problem Statement

空间音频现在有 5.1、7.1.4、不同房间、去相关、反射阶数等多组参数。用户想对比几套调好的配置时，只能手动逐项改回去，容易丢失，也不方便统一试听。需要把当前 SpatialSettings 快照保存成命名方案，并能一键切回。

## Solution

在空间音频页增加「我的空间方案」：保存当前空间快照到本机 localStorage，列表里点击即可恢复；支持删除，最多 20 条。方案只包含空间设置，不改变曲目/场景/音量；完全本地，不上传。

## User Stories

1. 作为用户，我想给当前布局/房间/强度组合起名保存，这样下次不用重新调。
2. 作为用户，我想一键切回某个空间方案，这样能快速比较 5.1 和 7.1.4。
3. 作为用户，我想删除不再需要的方案。
4. 作为用户，我想方案保存在本机、重启后仍在，不依赖账号。
5. 作为用户，我想保存方案不会修改当前设置，只有点击应用才切换。
6. 作为开发者，我想方案存储独立于全局场景快照，避免影响现有场景/分享串。

## Implementation Decisions

- 新增本机空间方案仓库：localStorage 键固定，最多 20 条，保存时深拷贝 SpatialSettings，损坏数据按空列表处理。
- UI 使用可折叠「我的空间方案」区：名称输入、保存当前方案、方案芯片点击应用、× 删除。
- 应用方案走现有 patch 参数提交路径；不新增引擎字段或 DSP 路径。
- 方案只保存空间快照；不保存曲目、系统音量、场景 ID。
- inputFormat 作为空间设置的一部分保存；从不同音源格式保存的方案会恢复当时的格式，UI 后续可提示。

## Testing Decisions

- 测试存储层：保存/按最新排序/深拷贝/删除/损坏 JSON。
- UI 后续测试可断言保存后芯片出现、点击后 bridge 参数变化。
- 参考 spatial-completion.test.tsx 与现有 localStorage store 测试。

## Out of Scope

- 云同步、跨设备同步。
- 方案导入/导出（后续可复用场景库格式另行做）。
- 修改引擎空间算法。

## Further Notes

方案是测试工具，不是新的音质算法；它让用户能保留几套调好的空间参数做统一 A/B。

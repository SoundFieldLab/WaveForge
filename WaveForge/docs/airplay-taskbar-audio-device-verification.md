## 二、实机验证清单（需要你手动确认）

### 1. AirPlay 投送（设置 → 高级 → AirPlay 投送）
- [ ] 打开开关，等待 1~2 秒，应看到局域网内的 AirPlay 设备列表（音箱 / Apple TV / 电视）
- [ ] 连接设备后状态变为「正在投送音频」，音箱应播放当前歌曲（延迟约 2 秒属正常，与电视投屏一致）
- [ ] 本地暂停 → 音箱停止；本地继续播放 → 音箱恢复（无需重连）
- [ ] 切歌 → 音箱切歌（不应先放出一段旧歌）
- [ ] 音量滑杆 / 跟随播放器音量开关生效
- [ ] 断开后回到「空闲」；同一设备再次连接正常
- 说明：本机无 AirPlay 音箱时列表为空属正常（smoke 已验证服务与发现链路）。AirPlay 2 设备（HomePod/Apple TV）请切「AirPlay2」协议；兼容性问题优先用「RAOP」。

### 2. 任务栏迷你播控（设置 → 个性化 → 任务栏迷你播控）
- [ ] 打开开关并播放歌曲 → 任务栏右侧（托盘左侧）出现与任务栏**等高**的迷你播控栏
- [ ] 显示当前歌词行（带逐字高亮）与下一句；无歌词时显示歌名/歌手
- [ ] 悬停 → 可点击（上一首/播放暂停/下一首/静音/进度条 seek）；移出 → 鼠标穿透，不挡任务栏
- [ ] 位置切「居中」、宽度滑杆实时生效
- [ ] 关闭开关 → 播控栏消失；重启应用后开关状态保持
- 说明：受限于 Electron 无原生任务栏窗口带能力（本机无 C++ 工具链），采用「精确贴合任务栏带尺寸 + 鼠标穿透」方案，视觉与交互上等同嵌入；真正嵌入任务栏带需要原生 Win32 程序（Echo 的做法），非本版本范围。

### 3. 音频输出设备（设置 → 高级 → 音频输出设备）
- [ ] 列表应准确列出当前电脑的音频输出设备（扬声器/耳机/蓝牙，带真实名称）
- [ ] 点击某设备 → 播放中的音乐立即切到该设备；提示「音频输出已切换」
- [ ] 蓝牙/HDMI 设备热插拔 → 列表自动刷新
- [ ] 选择「跟随系统默认」恢复
- [ ] 重启应用后仍保持上次选择的设备
- 说明：输出切换基于 `AudioContext.setSinkId`（WaveForge 全音频流经 Web Audio 图，打在此处可整体切换）。已实测枚举带真实标签。

### 4. 频谱分析（对比听感）
- [ ] 播放歌曲，观察播放页频谱 / 3D 频谱河 / 桌面播放器频谱：低频更饱满（下探 20Hz）、动态更细腻（dB 映射）、回落更自然（attack/decay 平滑）

### 5. 智能过渡（设置 → 高级 → 播放过渡 → AutoMix）
- [ ] 播放两首响度差异大的歌：过渡段音量衔接更顺滑（±3.5dB 响度补偿）
- [ ] 剩余时间不足 12 秒时不强行 AutoMix，自动走 Crossfade

## 三、已知边界（如实说明）
- AirPlay 投送仅在**桌面端**（Electron）可用；纯网页模式自动降级（设置卡片提示不支持）。
- 任务栏迷你播控仅 Windows；多显示器时贴主屏（v1）。
- AirPlay 会话不自动重连已选设备（每次需手动连接，防止意外投送）。
- AirPlay 2 音频为库作者标注的 "best-effort"；RAOP（AirPlay 1）路径最稳。

# ADR-0001: 音效可叠加模型 + 快照式场景方案

调音室原有"5 个音效互斥、同时只能开一个"的模型（远程 `c034a31` 引入）。要支持"重低音 = 低音增强 + 混响 + 全景"这类场景方案组合，互斥模型无法表达。决定改为：**每个音效独立开关、可任意叠加**；场景方案作为一组完整参数快照（快照式），点击即写入当前设置，手动微调后进入自定义状态，再次点击场景方案时提示覆盖或先保存为"我的场景"。

代价是调音室 UI 需重构（互斥卡片 + 使用按钮 → 场景方案区 + 独立开关列表）；好处是场景方案表达能力成立，与主流播放器行为一致。导出 WAV 与离线渲染链不受影响（见 ADR-0003）。
